Documentación

Guía rápida de uso y referencia de la API.
AYUDA

1. Cargar datos

Selecciona un archivo JSON o pega directamente su contenido. También puedes utilizar el botón «Cargar ejemplo» para probar la aplicación.

2. Configurar y procesar

Define la zona horaria y el orden de las fechas ambiguas. Después, pulsa «Normalizar transacciones» para ejecutar el procesamiento.

3. Revisar resultados

Consulta las métricas, los gráficos y las tablas de transacciones válidas e inválidas. Pulsa «Ver» para consultar el JSON original, el resultado normalizado y su trazabilidad.

4. Exportar

Copia el resultado estandarizado al portapapeles o descárgalo como archivo JSON.
