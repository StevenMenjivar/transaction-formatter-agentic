# Capturas del dashboard

Guarda aquí las capturas PNG de la aplicación ejecutándose en tu equipo. Consulta la sección **Capturas de pantalla en este README** del archivo principal para conocer los nombres recomendados, el contenido de cada captura y el código Markdown para insertarlas.

Recomendaciones:
- Capturar datos de demostración, nunca información financiera real.
- Mantener un tamaño legible y una resolución consistente.
- Recortar el escritorio para mostrar únicamente la ventana o el área relevante del dashboard.
- Utilizar nombres de archivo descriptivos y rutas relativas en el README.
